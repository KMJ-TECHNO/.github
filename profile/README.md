## What we build

**KMJ TECHNO** is developing tools that make software and infrastructure engineering more secure, accessible and verifiable.

| Focus | Project | Engineering goal |
|---|---|---|
| Authorized AI coding | [KMJ CodeBridge](https://github.com/kmjtechno/kmj-codebridge) | Project-scoped AI engineering, tests and explicit approvals |
| Resilient remote access | [KMJ OmniDesk](https://github.com/kmjtechno/kmj-omnidesk) | Secure, bandwidth-conscious remote connectivity |
| Free-first engineering | [KMJ Forge](https://github.com/kmjtechno/kmj-forge) | Provider-agnostic, local-capable engineering workflows |
| Remote development tools | [KMJ Desktop Commander](https://github.com/kmjtechno/kmj-desktop-commander) | Permission-controlled engineering operations |

Projects have different readiness levels; **development or preview features must not be presented as generally available**. Refer to each repository's README and releases for verified status.

## How we work

- **Security first.** Least privilege, explicit authorization and safe defaults.
- **Verification over claims.** Build, test and reproduce engineering outcomes.
- **Efficient by design.** Prefer existing hardware and compliant free/included tooling before metered services.
- **Interoperable systems.** Clear integration boundaries and portable interfaces.
- **Responsible collaboration.** Do not post credentials, private code or sensitive customer information in public issues.
